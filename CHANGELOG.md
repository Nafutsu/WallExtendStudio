# Changelog

## 0.1.0 — Initial project

- Added a Miuix-themed Android interface for choosing and editing wallpaper images.
- Added device-resolution detection and a real-time, screen-ratio preview.
- Added edge stretch, mirrored extension, blur fill, cover crop, and full stretch modes.
- Added scale and vertical-position controls.
- Added EXIF-aware image decoding, MediaStore export, and direct wallpaper application.
